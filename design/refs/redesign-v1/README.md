## Решения по рефам

- Палитра: тёмно-фиолетовая база + лаймовый акцент.
- 3D-предметы (жизнь, подсказки, серия, итог ответа) — генерация в Magnific.
- Шрифт: только Inter (одно семейство) вместо Geist.
- Токены: тема shadcn расширяется своими (`--success`, `--warning`,
  `--glow-*`, `--gradient-*`); в Figma — новый режим коллекции, вайрфреймы
  остаются в исходном режиме.
